To build and start Jenkins container, use this command:
docker compose -f docker-compose.devops.yml up -d --build 

If you ever need to make changes to the jenkins pipeline, push changes to the remote repo, then run these commands in terminal to fully replace it afterwards:
docker compose -f docker-compose.devops.yml down
docker compose -f docker-compose.devops.yml up -d --build 

Verify Jenkins is running with this command:
docker ps

After that, go to http://localhost:8088 to use the jenkins console.
