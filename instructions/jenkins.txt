Ensure your jenkins/Dockerfile is updated with the Docker CLI installation and jenkins user group logic.
Ensure docker-compose.devops.yml includes the Postgres service and the jenkins service has the /var/run/docker.sock volume mapping.

To build and start Jenkins container, use this command:
docker compose -f docker-compose.devops.yml up -d --build 

Enable docker out of docker(IMPORTANT) -- already baked into dockerfile, but MUST run this command for permissions:
Run this on your LOCAL terminal (Mac/Linux/WSL)
sudo chmod 666 /var/run/docker.sock

After that, go to http://localhost:8088 to use the jenkins console.

Configure the pipeline with our remote repository link, set the branch you want to poll.
Go to triggers part of the pipeline configuration and select Poll SCM, then set the schedule as H/5 * * * *
This has Jenkins poll the repo every 5 minutes for changes.
Because it's branch specific, we need to update this configuration before merging to main. Remember to put */ before the branch name like this: */main

Click build now and make sure that it doesn't fail!
