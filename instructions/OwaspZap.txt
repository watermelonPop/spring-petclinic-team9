OWASP ZAP Stage Guide

This file explains how to run the OWASP ZAP part of the Jenkins pipeline and what that stage is doing internally.

How to run this part of the pipeline

Option A: Run full pipeline (recommended)
1. Open Jenkins: `http://localhost:8088`
2. Open your pipeline job.
3. Click `Build Now`.
4. Watch stage: `OWASP ZAP Security Scan`.
5. After completion, open stage: `Publish ZAP HTML Report`.
6. Open report link: `OWASP ZAP Report`.

Prerequisites
- Jenkins container is running and healthy.
- Build stage has produced: `target/spring-petclinic.jar`.
- Jenkins can run Docker commands.
- HTML Publisher plugin is installed (used by `Publish ZAP HTML Report`).

What the `OWASP ZAP Security Scan` stage does
1. Enables strict shell behavior
- `set -euo pipefail`
- Fails fast for script errors and unset variables.

2. Starts the app for scanning
- Runs Spring Petclinic JAR in background on port `8081`:
	`java -jar target/spring-petclinic.jar --server.port=8081 > spring.log 2>&1 &`
- Stores process id in `APP_PID` so it can be stopped later.

3. Waits for startup
- Sleeps 30 seconds before scanning.

4. Prepares report folder
- Creates `zap-reports/`.
- Removes old `zap_report.html` if present.

5. Runs OWASP ZAP baseline scan in container
- Removes stale scanner container name `zap-scan`.
- Runs:
	`ghcr.io/zaproxy/zaproxy:stable`
- Network mode:
	`--network container:petclinic-jenkins`
	so ZAP can access app as `http://localhost:8081`.
- Executes baseline script:
	`python3 /zap/zap-baseline.py -t http://localhost:8081 -r zap_report.html -I`

6. Copies generated report to Jenkins workspace
- Copies from container path:
	`/zap/wrk/zap_report.html`
- Stores in workspace path:
	`zap-reports/zap_report.html`

7. Cleans up
- Removes scanner container.
- Stops background app process using `kill $APP_PID`.

What `Publish ZAP HTML Report` stage does
- Publishes `zap-reports/zap_report.html` in Jenkins UI.
- Archives the same file as a build artifact.

Expected output
- Console logs show ZAP scan activity and warnings.
- Jenkins build page includes link: `OWASP ZAP Report`.
- Artifact exists: `zap-reports/zap_report.html`.

Troubleshooting
- Report missing:
	Check whether `docker cp zap-scan:/zap/wrk/zap_report.html zap-reports/zap_report.html` succeeded.
- App not reachable by ZAP:
	Increase startup wait (`sleep`) or verify JAR starts on port `8081`.
- Docker permission errors in Jenkins:
	Ensure Jenkins container has access to `/var/run/docker.sock` and correct Docker group permissions.
- Stage passes with warnings:
	This is expected with `-I` (do not fail build on alerts). Remove `-I` if you want strict failure behavior.
